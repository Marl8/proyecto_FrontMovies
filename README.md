<h1 align="center">📺 Proyecto FrontMovies 📺</h1>

<br/>

Proyecto final para la materia Frontend en el marco de la carrera Tecnicatura Superior en Desarrollo de Software
impartida por el IFTS Nª 29. El mismo consiste en una aplicacón de streaming de películas y series realizada con HTML, CSS y JavaScript
consumiendo la API de [TheMoviedb.org](https://developer.themoviedb.org/docs/getting-started).

También se utilizó mockApi para simular la gestión de autenticación de usuarios.
